# AI-Based Waste Detection and Monitoring

Research project for waste detection, monocular depth estimation,
camera calibration investigation, and preliminary volume estimation.

## Modules
1. Dataset inspection and preparation
2. YOLOv8n waste detection
3. MiDaS depth estimation
4. Camera calibration and scale estimation
5. Preliminary volume estimation

## Project structure
- `src/dataset/`: dataset preparation
- `src/detection/`: detection, training, and evaluation
- `src/depth/`: depth estimation
- `src/calibration/`: calibration and scale estimation
- `src/volume/`: volume estimation
- `configs/`: configuration files
- `tests/`: automated tests
- `outputs/`: generated results

## Status
Initial project setup. Model training and evaluation results will be
documented only after actual execution and testing.

## Important
Datasets, model checkpoints, and generated outputs are not stored in
ordinary Git commits. Back them up separately.
